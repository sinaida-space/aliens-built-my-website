# Process — how work ships in this repo

- **`gh-workflow.md`** — issues-as-task-manager and branch hygiene for
  syncing work to `sinaida-space/aliens-built-my-website`: an issue per
  feature/page, a branch per issue, PR back to `main`, confirm before each
  push.

One file, its own folder — kept separate from `compliance/`, `design/`,
`growth/`, and `ux/` because it’s the only reference here about *how the
work gets shipped*, not about a quality bar the shipped result has to clear.
