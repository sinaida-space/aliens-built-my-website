# Growth — findability by non-human visitors

How a site gets found and used by things that aren’t a human reading the
page: search engines and AI agents/crawlers.

- **`seo-checklist.md`** — technical SEO checklist (semantic structure, meta
  tags, sitemap, robots.txt), curated from the
  [claude-seo](https://github.com/AgriciDaniel/claude-seo) project’s
  checklist knowledge only (see the note at the bottom of `SKILL.md`).
- **`agentic-readiness.md`** — checklist distilled from
  [isitagentready.com](https://isitagentready.com): `robots.txt` AI-bot
  rules, sitemap, `llms.txt`, MCP Server Card, and (commerce sites only)
  deeper protocol items.

## Priority

Lower priority than `compliance/` or `design/` for a plain portfolio or
marketing site — the quick wins (robots.txt rules, `llms.txt`, real semantic
HTML) still apply everywhere, but the deeper protocol/commerce items in
`agentic-readiness.md` only matter once a site has an API, MCP server, or
storefront to expose.
