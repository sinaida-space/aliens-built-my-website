# Assets — source material, not part of the skill itself

Everything the skill’s reference docs were distilled from, or that exists
purely to set the aesthetic tone of this repo. None of these files are read
by the skill at runtime — they’re provenance and mood, kept for context.

- **`mood-board/`** — the visual register this project keeps in mind even
  when the actual deliverable is a privacy policy: aliens, CRT terminals,
  roses, neon. Referenced by `README.md` at the repo root.
- **`research/`** — the source document(s) a reference file’s checklist was
  distilled from, so the origin of a claim is traceable instead of taken on
  faith.
